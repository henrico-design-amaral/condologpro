# CondoLogOPS — Marketing Design Resolver

Status: ACTIVE
Version: 1.0
Date: 2026-09-01
Authority: `STYLE_GUIDE.md` + `DESIGN_SYSTEM.md` + current accepted marketing implementation + project decisions

## Role
Thin agent-facing visual resolver for the CondoLogOPS marketing surface.

## Before visual work
Resolve:
- semantic project name `CondoLogOPS` versus legacy technical paths;
- requested marketing surface/section;
- current accepted implementation/assets;
- product claim/evidence source;
- applicable Reference Pack;
- responsive/A11Y requirements;
- fidelity mode when an approved artifact is the source.

## Protected
- marketing/app separation;
- factual process/evidence representation;
- current accepted visual anchors until explicitly superseded;
- no claim of app production availability without evidence;
- no invented operational metrics/screens.

## V2/V3 flow
`direction -> visual decoupage -> composition/responsive contract -> browser prototype -> section implementation -> visual/A11Y QA`

The implementer is not allowed to invent missing product, brand or responsive decisions in production code.

## HVS
Henrico Visual System validates quality/accessibility/system discipline but does not choose CondoLogOPS aesthetics.

## Failure
If a material visual authority cannot be resolved from current implementation/assets/decisions, route to Visual Foundation instead of improvising.
