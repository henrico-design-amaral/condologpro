# DECISIONS — CondoLogPro

## 2026-05-29 — Decisão 001

O produto será iniciado como MVP local-first, não como SaaS cloud completo.

Motivo:
O primeiro objetivo é validar o fluxo real em condomínio, com uso mobile na portaria e admin desktop. A complexidade de billing, cloud e WhatsApp API oficial será adiada.

## 2026-05-29 — Decisão 002

O WhatsApp no MVP será assistido por link/mensagem pronta.

Motivo:
A administração já possui número institucional. A integração oficial via WhatsApp Cloud API exige setup, aprovação e templates. Para protótipo real, o envio assistido reduz fricção e mantém o fluxo compatível com a rotina atual.

## 2026-05-29 — Decisão 003

O OCR não será requisito bloqueante para o primeiro teste.

Motivo:
OCR de etiqueta varia por transportadora, iluminação e qualidade da foto. O MVP deve permitir foto da etiqueta e associação manual rápida com fallback confiável.

## 2026-05-29 — Decisão 004

A interface mobile será prioridade operacional.

Motivo:
O registro acontece na portaria, em movimento, com pouco tempo e possível pressão de fila.
