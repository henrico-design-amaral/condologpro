# CondoLogOPS — Marketing Accessibility Contract

Status: ACTIVE
Version: 1.0
Date: 2026-09-01
Authority: HenricoOPS A11Y Gate

## Baseline
The public marketing surface targets WCAG 2.2 AA.

Required:
- semantic landmarks/headings;
- keyboard-operable navigation/actions;
- visible focus;
- sufficient contrast;
- meaningful alt text;
- color not used as sole meaning;
- touch-friendly targets;
- 320px+ reflow with no uncontrolled horizontal overflow;
- reduced-motion support;
- understandable form/error/status behavior when applicable.

No local exception is approved by this file. Any weaker behavior requires an explicit recorded exception.
