# session-start skill

Use this at the beginning of every CondoLogPro work session.

Steps:
1. Run git status -sb.
2. Run git branch --show-current.
3. Read CLAUDE.md.
4. Read PROJECT_CONTROL.md.
5. Read TASKS.md.
6. Read DECISIONS.md.
7. Identify current project phase.
8. Report risks before editing.
