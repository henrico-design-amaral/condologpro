# pdr-compliance-review skill

Use this before closing any implementation task.

Checklist:
1. Does the change match the PDR?
2. Did it create any out-of-scope module?
3. Does it preserve local-first behavior?
4. Does it support the real condominium workflow?
5. Is UI in Brazilian Portuguese?
6. Is source code naming in English?
7. Are TASKS, PROJECT_CONTROL or HANDOFF updates needed?
