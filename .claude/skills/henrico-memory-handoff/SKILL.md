# Henrico Memory Handoff

Registrar:
1. Projeto.
2. Branch.
3. Commit, se houver.
4. Arquivos alterados.
5. Validação feita.
6. O que não foi validado.
7. Riscos.
8. Próximo passo recomendado.
9. Estado do working tree.
10. Se houve ou não deploy.

Não romantizar.
Não resumir demais.
Não inventar validação.
