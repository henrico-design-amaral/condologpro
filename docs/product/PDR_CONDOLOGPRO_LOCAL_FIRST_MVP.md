# PDR — CondoLogPro Local-First MVP

## Produto

CondoLogPro

## Categoria

Sistema local-first para gestão operacional de encomendas condominiais.

## Objetivo

Criar um MVP funcional para teste real em condomínio, com uso mobile na portaria e desktop na administração.

## Fluxo-base do condomínio

1. Portaria/administração recebe pacote.
2. Operador fotografa a etiqueta.
3. Sistema cria entrada da encomenda.
4. Operador associa bloco, apartamento e morador.
5. Sistema gera mensagem pronta para WhatsApp.
6. Morador retira encomenda.
7. Operador registra baixa digital.

## Prioridade absoluta

Funcionar no fluxo real antes de expandir para outros módulos.

## Fora de escopo inicial

- Cobrança.
- Multi-tenant SaaS completo.
- WhatsApp Cloud API.
- OCR obrigatório.
- Aplicativo nativo.
- Módulo de manutenção.
- Módulo de comunicados.
