# Checklist operacional de piloto

## Abertura

- [ ] HTTPS e domínio corretos.
- [ ] Usuário ativo e condomínio exibido corretamente.
- [ ] Câmera traseira abre em aparelho físico.
- [ ] Escolha de arquivo funciona como fallback.
- [ ] Portaria não acessa administração.

## Recebimento

- [ ] Foto legível, preview e recaptura.
- [ ] OCR sugere sem salvar sozinho.
- [ ] Correção manual permanece disponível.
- [ ] Busca por nome, bloco, unidade e termo parcial.
- [ ] Telefone aparece mascarado.
- [ ] Destinatário não encontrado pode seguir com observação.
- [ ] Provável duplicidade exige decisão registrada.
- [ ] Reload após salvar preserva imagem e dados.

## Comunicação

- [ ] Template identifica condomínio e unidade.
- [ ] Abrir WhatsApp não altera status.
- [ ] Confirmar envio cria histórico com operador/data.
- [ ] Nova tentativa permanece possível.

## Retirada

- [ ] Busca localiza nome, unidade ou código.
- [ ] Nome de quem retira e relação são obrigatórios.
- [ ] Documento é parcial e comprovante é opcional.
- [ ] Confirmação aparece antes da baixa.
- [ ] Segundo operador recebe conflito, não duplica retirada.
- [ ] Item sai da fila e continua consultável.

## Encerramento

- [ ] Sem erro crítico no console.
- [ ] Sem request para Vercel, SQLite ou endpoint local.
- [ ] Imagens não abrem por URL pública.
- [ ] Logout invalida a superfície operacional.
- [ ] Evidência registrada sem expor PII.
